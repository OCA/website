To configure the reseller page header:
* Make sure the correct website is selected. If necessary, switch to the website whose reseller page header you want to customize.
* Go to **Website > Configuration > Settings**.
* Locate the **Reseller Page Header** setting.
* Enter the desired default heading text in the corresponding field.
* To configure translations, use the translation option available for the field in the settings. Enter the appropriate translated value for each installed language.
* Click **Save** to apply your changes.
* Open the reseller directory page in the respective website languages to verify the displayed headings.
* To restore the default header, enter `Find a reseller` and save the settings. Update the translations accordingly if necessary.

**Note:** The configured header applies only to the selected website. Different websites can use different reseller page header.
