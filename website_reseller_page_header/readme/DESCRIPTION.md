## Website Reseller Page Header
This module allows users to customize the heading displayed on the reseller directory page in Odoo Website.
It adds a configurable reseller page header to the website settings.

### Features
* Add a configurable reseller page header to the website settings.
* Configure the reseller page header independently for each website.
* Support translated reseller page header for different website languages.
* Display the configured header dynamically on the reseller directory page.
* Preserve the existing country filter and dynamic country name display.

The reseller page header is stored directly on the website model. This allows each website to maintain its own heading independently.
