This module lets website editors embed video files hosted on their own
server or on a CDN, next to the YouTube, Vimeo, Dailymotion, Instagram and
Facebook videos supported by Odoo.

Such videos are played with the browser's native HTML5 `<video>` player, so
no third-party player or cookies are involved. They can be used:

- as a video block in a page, with the usual options (autoplay, loop, hide
  player controls, start at);
- as a section background video, played muted and in a loop, covering the
  whole section.
