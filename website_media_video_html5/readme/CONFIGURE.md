URLs ending with a video file extension (`.mp4`, `.m4v`, `.webm`, `.ogv`,
`.ogg`) are accepted without configuration.

Many CDNs serve videos from URLs without a file extension. To allow them, go
to *Website \> Configuration \> Settings*, and list the hosts serving these
videos in *Self-hosted videos*, separated by commas (e.g.
`res.cloudinary.com`). Subdomains of these hosts are allowed as well.
