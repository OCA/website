To add a video to a page:

1.  Edit the page, and add a video block or replace a media (*Replace* button
    of an image).
2.  In the *Videos* tab, paste the URL of the video file, e.g.
    `https://cdn.example.com/videos/product.mp4`.
3.  Choose the player options and click *Add*.

To use a video as section background, select the section, enable the
*Video* background option and paste the URL of the video file the same way.

As for other platforms, the player options are stored in the video URL; they
are removed from the URL the browser loads, so signed CDN URLs keep working.
