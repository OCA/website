This module lets website editors embed video files hosted on their own
server or on a CDN, next to the YouTube, Vimeo, Dailymotion, Instagram
and Facebook videos supported by Odoo.

Such videos are played with the browser's native HTML5 ``<video>``
player, so no third-party player or cookies are involved. They can be
used:

- as a video block in a page, with the usual options (autoplay, loop,
  hide player controls, start at);
- as a section background video, played muted and in a loop, covering
  the whole section.

Configuration
=============

URLs ending with a video file extension (``.mp4``, ``.m4v``, ``.webm``,
``.ogv``, ``.ogg``) are accepted without configuration.

Many CDNs serve videos from URLs without a file extension. To allow
them, go to *Website > Configuration > Settings*, and list the hosts
serving these videos in *Self-hosted videos*, separated by commas (e.g.
``res.cloudinary.com``). Subdomains of these hosts are allowed as well.

Usage
=====

To add a video to a page:

1. Edit the page, and add a video block or replace a media (*Replace*
   button of an image).
2. In the *Videos* tab, paste the URL of the video file, e.g.
   ``https://cdn.example.com/videos/product.mp4``.
3. Choose the player options and click *Add*.

To use a video as section background, select the section, enable the
*Video* background option and paste the URL of the video file the same
way.

As for other platforms, the player options are stored in the video URL;
they are removed from the URL the browser loads, so signed CDN URLs keep
working.

Known issues / Roadmap
======================

- Support HTTP Live Streaming (``.m3u8``) playlists, which need a
  JavaScript player outside of Safari.
- Generate a poster image from the video.
