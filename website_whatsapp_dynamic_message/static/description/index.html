Website WhatsApp Dynamic Message

This module extends the OCA website_whatsapp module to provide context-aware dynamic WhatsApp messages for product pages.

When visitors browse your website, the WhatsApp button automatically adapts its message based on the page they’re viewing:

  • Product pages: Generates a personalized message that includes the product name, making it easy for customers to inquire about specific products
  • Other pages (homepage, contact, about, etc.): Uses the default message configured in your website settings

The module seamlessly integrates with the existing website_whatsapp configuration and requires no additional setup. It maintains full backward compatibility with the base module, preserving all existing functionality including URL tracking and custom message configuration.

Key Features:

  • Automatic product name inclusion in WhatsApp messages on product pages
  • Proper handling of special characters and Unicode in product names
  • Support for URL tracking on both product and non-product pages
  • Translatable message templates for multilingual websites
  • Zero configuration required - works immediately after installation

Configuration

Configuration

No additional configuration is required for this module. It automatically extends the functionality of the website_whatsapp module.

The module uses the existing WhatsApp configuration from the base website_whatsapp module. To configure WhatsApp settings:

  1. Go to Website > Configuration > Settings
  2. Scroll to the WhatsApp section
  3. Configure the following fields:
    • whatsapp_number: The WhatsApp phone number (with country code) where messages will be sent
    • whatsapp_text: The default message text for non-product pages (homepage, contact, etc.)
    • whatsapp_track_url: Enable to append the current page URL to WhatsApp messages

Once configured, the module will automatically:

  • Use dynamic product-specific messages on product pages
  • Use the default whatsapp_text message on all other pages
  • Append the page URL to messages when whatsapp_track_url is enabled

Usage

Once installed, the module automatically provides context-aware WhatsApp messages without requiring any additional configuration.

Behavior on Product Pages

When a visitor views a product page, the WhatsApp button automatically generates a personalized message that includes the product name.

**Example:**

If a visitor is viewing a product named "Wireless Headphones", clicking the WhatsApp button will open WhatsApp with the message:

    Hello, I'm interested in product Wireless Headphones, I would like more information

The product name is automatically inserted into the message, making it easy for visitors to inquire about specific products without typing manually.

Behavior on Other Pages
~~~~~~~~~~~~~~~~~~~~~~~~

On all other pages (homepage, contact page, about page, etc.), the WhatsApp button uses the default message configured in your website settings.

**Example:**

If your default message is "Hello, how can we help you?", visitors on the homepage will see this message when clicking the WhatsApp button.

Track URL Feature
~~~~~~~~~~~~~~~~~

If you have enabled the "Track URL" option in website settings, the current page URL will be automatically appended to the message on all pages.

**Example on a product page:**

    Hello, I'm interested in product Wireless Headphones, I would like more information
    https://yourwebsite.com/shop/wireless-headphones

**Example on the homepage:**

    Hello, how can we help you?
    https://yourwebsite.com/

Translation Support
~~~~~~~~~~~~~~~~~~~

The dynamic message template is fully translatable. When visitors view your website in different languages, they will see the message template in their preferred language, while the product name remains in its original form.

**Example in Spanish:**

    Hola, estoy interesado en el producto Wireless Headphones, me gustaría más información

To translate the message template, go to Settings > Translations > Application Terms > Translated Terms and search for the message text.
