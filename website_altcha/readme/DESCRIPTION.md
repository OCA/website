This module allows to use a Captcha System completly handled by Odoo.

It relies on Altcha (https://altcha.org), an OpenSource captcha alternative.

### Third-party libraries

- [ALTCHA](https://github.com/altcha-org/altcha) **v3.5.0** (MIT License), updated on 2026-10-28.
  Vendored file: [`dist/main/altcha.i18n.js`](https://github.com/altcha-org/altcha/blob/v3.5.0/dist/main/altcha.i18n.js)
