Adds editable website builder areas to the login page.

**Table of contents**

.. contents::
   :local:

Usage
=====

#. Go to the login page: ``/web/login``. #. Open the website editor. #.
Select a content block from the editor sidebar. #. Drag it to one of the
editable areas available on the login page:

- above the login form
- below the login form

#. Save the page.
