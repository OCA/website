1. Edit a page that contains a Form snippet.
2. Click the form to open its options in the sidebar.
3. Open the "Columns" row and pick 1, 2, 3 or 4.
4. Drag any field from one column to another. Drop targets highlight on
   hover. Empty columns remain droppable thanks to a minimum height.
5. On mobile (<768px) columns stack vertically by default.
