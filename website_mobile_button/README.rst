This module adds a fixed navigation bar at the bottom of the website on
mobile devices, similar to the tab bar of a mobile app.

Features:

- The bar can be enabled or disabled for each website from the website
  editor.
- Buttons are fully editable with the website editor: icon or logo,
  label, link, colors and size.
- Each button is a building block that can be dragged into the bar,
  duplicated, reordered or removed.
- The whole button area is clickable, not only its text.
- Separators between buttons, background color and shadow of the bar are
  configurable.
- The content is stored per website, so each website can have a
  different bar.
- The bar is only displayed on small screens (below the ``lg`` Bootstrap
  breakpoint).

Usage
=====

To enable the bottom bar on a website:

1. Go to the website you want to configure and click **Edit**.
2. Open the **Customize** tab.
3. Enable the **Mobile Bottom Bar** option.

The bar is hidden on large screens, but it is always displayed while
editing so it can be configured from a desktop. Use the mobile preview
of the editor to see how it will look on a phone.

To edit a button:

1. Click on the icon, or double-click it to replace it with another icon
   or with an image (logo).
2. Click on the label to change the text.
3. Click on the button outside the icon and the text (its padding area)
   to select the whole button. In the options panel you can set:

   - **Link (URL)** and **Open in new tab**.
   - **Background** and **Text / icon color**.
   - **Label**: show or hide the text.
   - **Icon size**.

Do not use the editor link tool on the label: the link is set from the
button options, which makes the whole button clickable.

To add, duplicate, move or remove buttons:

1. Drag the **Bottom Bar Button** block from the blocks panel into the
   bar, or use the duplicate and delete icons on a selected button.
2. Drag buttons to change their order.

To configure the whole bar, click on the bar outside any button. The
options panel allows to change:

- **Background** color.
- **Shadow**: none, small or medium.
- **Separators** between buttons: line, short line or none.

Changes are saved per website. In a multi-website database, repeat the
configuration on each website.
