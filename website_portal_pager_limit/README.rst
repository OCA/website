This module adds a page size selector to portal pages in Odoo.

Users can choose how many records are displayed per page using a dropdown
integrated into the portal pager. The selected value is applied via a
``limit`` query parameter and affects pagination behavior accordingly.

Key features:

- Adds a page size selector to the portal pager
- Supports configurable limit options (e.g. 10, 20, 40, 80, 100)

Use Cases / Context
===================

This module extends the standard Odoo portal pager to allow end users to
control the number of records displayed per page.

By default, Odoo portal pages (such as orders, invoices, or tickets) use a
fixed limit defined in the controller. This limit cannot be adjusted by the
user, which may lead to suboptimal usability when browsing large datasets.

Configuration
=============

To configure the page limit options:

#. Go to *Settings → Technical → Parameters → System Parameters*.
#. Edit the ``website_portal_pager_limit.options`` parameter with a
   comma-separated list of integers (e.g. ``10,20,40,80,100``).

Only values defined in the options list will be accepted. Any invalid or
unsupported value will fall back to the default.

Usage
=====

Navigate to any portal page that displays a list of records, such as:

- My Invoices
- My Quotations

A page size selector is displayed alongside the pager controls. Pick a value
to change the number of records displayed per page; the choice is kept while
paginating, sorting, filtering and searching.
