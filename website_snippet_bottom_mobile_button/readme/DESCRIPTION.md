This module adds a fixed navigation bar at the bottom of the website on mobile devices, similar to the tab bar of a mobile app.

Features:

- The bar can be enabled or disabled for each website from the website editor.
- Buttons are fully editable with the website editor: icon or logo, label, link, colors and size.
- Each button is a building block that can be dragged into the bar, duplicated, reordered or removed.
- The whole button area is clickable, not only its text.
- Separators between buttons, background color and shadow of the bar are configurable.
- The content is stored per website, so each website can have a different bar.
- The bar is only displayed on small screens (below the `lg` Bootstrap breakpoint).
