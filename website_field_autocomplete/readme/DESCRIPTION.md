This module adds an autocomplete interaction to Odoo website forms.

It searches records from any model readable by the website's public user and
displays matching suggestions while the visitor types. The displayed label and
the value submitted by the form can be configured independently, making it
possible to use the interaction with relational fields such as `Many2one`.

The module uses Odoo's public interactions and does not require jQuery UI or
any other frontend autocomplete library.
